# Vmestra: MVP и UX-направление

## Текущий фокус

Сейчас цель — не писать код, а уточнить MVP и UX.

MVP пока не зафиксирован окончательно. Нужно исследовать, какой минимальный продукт даст ощущение ценности:

- идеи не теряются;
- их можно быстро добавить;
- их можно разложить по папкам и тегам;
- можно открыть пространство и выбрать, чем заняться;
- можно запланировать идею;
- можно увидеть историю.

## Предварительный MVP-кандидат

Это не финальное решение, а рабочая гипотеза:

1. Личное пространство создаётся автоматически.
2. Можно создать группу и добавить участников.
3. Можно создать идею из короткого текста.
4. Можно назначить папку, теги и категорию.
5. Есть `Входящие` для неразобранных идей.
6. Есть список идей внутри выбранного пространства.
7. Есть простые рекомендации по тегам и фильтрам.
8. Есть планирование идеи с выбором участников.
9. Есть календарный вид.
10. Есть история пространства.
11. Есть профиль и мини-онбординг.
12. Есть тёмный режим.

## Явно не MVP

- Полноценная AI/LLM-интеграция.
- Реальные push-уведомления.
- Сложная ролевая модель.
- Глобальный поиск по всем пространствам.
- Поиск дублей между пространствами.
- Социальная сеть или публичные идеи.
- Голосование как обязательная часть первого UX-фокуса.

## UX-цели

Интерфейс должен быть desktop-first для тестирования на компьютере, но с будущей адаптацией под мобильное использование.

Ощущение интерфейса:

- спокойный;
- понятный;
- не корпоративный таск-менеджер;
- не перегруженный;
- с ощущением личной/групповой копилки идей;
- с аккуратным местом для рекомендаций.

## Онбординг

Нужен скипабельный мини-онбординг:

- создать идею;
- открыть профиль;
- добавить друзей;
- создать группу;
- проголосовать или отметить отношение к идее, если голосование будет показано в UX;
- запланировать идею;
- открыть историю.

## UX-вопросы к Front

Front должен подготовить несколько визуальных/UX-направлений и показать различия:

1. Спокойный минималистичный интерфейс.
2. Более тёплый и личный интерфейс.
3. Более продуктовый dashboard-интерфейс, но без ощущения таск-менеджера.

Для каждого направления нужно показать:

- главный экран пространств;
- экран одного пространства;
- быстрое добавление идеи;
- блок рекомендаций;
- планирование и календарь;
- историю;
- тёмный режим или принцип его работы.

## UX-риски

- Слишком похожее на таск-менеджер.
- Слишком много сущностей на первом экране.
- AI-рекомендации выглядят как обещание, которого MVP пока не выполняет.
- Группы и личное пространство смешиваются визуально.
- Календарь начинает доминировать над идеями.
